About these checks

Each history bar shows the latest completed check in its period. Its colour is the identity assessment. Hatching means the API was unavailable, so no fingerprint could be taken. A tick above a bar marks a checker version change.

Fingerprints compare responses against reference models. They do not authenticate a provider's backend, and candidate weights are relative within the reference library. Availability counts successful probes from this machine, not continuous uptime.
